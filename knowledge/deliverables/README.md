# Deliverables

Audience-facing communications produced by `/make-deliverable` and owned by `comms-lead` — executive updates,
announcements, steering-committee packs, briefing notes. Named `YYYY-MM-DD-<audience>-<topic>.md`. Start from
`templates/exec-update.md`, `templates/status-report.md`, or `templates/steerco-pack.md` depending on the
audience.

These are **renderings, not sources.** Every number and claim traces back to a `knowledge/` file; nothing is
first stated here. If a deliverable needs a fact that doesn't exist upstream, go create it upstream first.

Deliverables are point-in-time. They are never updated after circulation — supersede them with a new dated file
so the record of what was said, when, stays intact.
