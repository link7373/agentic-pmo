# Ceremonies

Ceremony notes produced by `/run-ceremony`. One file per event, named `YYYY-MM-DD-<type>.md`
(type = planning / standup / review / retro). Capture decisions, action items (owner + due), and open
questions — not transcripts. Impediments flow to `knowledge/raid-log.md`.
