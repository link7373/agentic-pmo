# Portfolio artifacts

Portfolio-level artifacts produced by `portfolio-analyst`. The canonical register lives one level up in
`knowledge/portfolio.md`; this directory holds the dated outputs of each cycle.

| Artifact | Produced by | Naming | Starts from |
|----------|-------------|--------|-------------|
| Portfolio report (two-tier) | `/track-portfolio` | `YYYY-MM-DD-portfolio-report.md` | `templates/portfolio-report.md` |
| Intake quality review | `/review-portfolio-intake` | `YYYY-MM-DD-intake-review.md` | — |
| Demand & capacity cycle | `/track-portfolio` | `YYYY-MM-DD-capacity-cycle.md` | — |
| Dashboard spec | `/design-dashboard` | `dashboard-<surface>.md` | `templates/dashboard-spec.md` |
| Automation spec | `/plan-portfolio-automation` | `automation-<flow>.md` | `templates/automation-spec.md` |

Dashboard and automation specs are living documents — update in place rather than dating them, so there is one
current definition of each surface and flow.
