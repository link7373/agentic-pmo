# Lessons Learned

> **The organization's memory.** Appended by `/close-project` and by the retrospective path of
> `/run-ceremony`; curated by `governance-lead`.
>
> A lesson only earns a row here if it would change what someone does next time. "Communication could be
> better" is not a lesson; "we sized the data migration from the vendor's row counts, which excluded archived
> records — get a live count before baselining" is. Every lesson names the change it implies, and the
> `Applied where` column is what stops this becoming a graveyard.
