# Status

Status reports and health scorecards produced by `/track-status`, owned by `delivery-monitor` and formatted by
`comms-lead`. One file per reporting period, named `YYYY-MM-DD-<project-or-team>-status.md`. Start from
`templates/status-report.md`.

Team-health and agile metrics from `scrum-master` land here too, as `YYYY-MM-DD-<team>-health.md`.

RAG is never a bare color: every status carries a reason and an action
(`standards/communication-standards.md`). Risks and issues raised while reporting go to
`knowledge/raid-log.md` under the ownership rules stated there — not into the report alone.
