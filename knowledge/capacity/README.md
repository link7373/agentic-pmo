# Capacity

Capacity and demand-vs-supply plans produced by `/plan-capacity`, owned by `program-manager` with data from
`resource-manager` and `portfolio-analyst`. One file per planning cycle, named
`YYYY-MM-DD-<cycle>-capacity.md`. Start from `templates/capacity-plan.md`.

Supply comes from `knowledge/resources.md`, demand from `knowledge/portfolio.md` and the project plans. State
which of the two any conclusion rests on — a capacity answer that silently mixes team velocity with named-person
allocation is the classic way this goes wrong.

Report by role or team. Individual allocation rows stay in `knowledge/resources.md` and out of anything
stakeholder-facing.
