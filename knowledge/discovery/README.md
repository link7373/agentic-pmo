# Discovery

Research artifacts produced by `/run-discovery` and owned by `discovery-researcher`. One file per study,
personas set, or synthesis, named `YYYY-MM-DD-<topic>.md`. Personas start from `templates/persona.md`.

Validated learnings graduate to `knowledge/product-context.md` — this directory holds the evidence, that file
holds the conclusion. Always record how strongly a finding is supported (observed behavior beats stated
preference) so a later reader can weigh it.
